Verified data sources

Quran, translation, tafsir, and recitation are loaded live from named APIs. This app does not author or edit that text in code.

Authenticity (what we rely on)

  • Riwaya: Hafs 'an 'Asim — standard for Uthmani and Indo-Pak API editions.
  • Uthmani mushaf: Al Quran Cloud catalog (Tanzil / Islamic Network), e.g. quran-uthmani.
  • Indo-Pak Naskh: Quran.com text_indopak (Hifzi-style ayah text, by surah).
  • Translation: Sahih International via en.sahih only (default).
  • Tafsir: Named works only; API edition IDs match scholar/work labels in the Tafsir menu.

Arabic Quran (Hafs Uthmani & formats)

Al Quran Cloud — standard editions (e.g. quran-uthmani, Tajweed, simple scripts). Based on widely used mushaf text (Tanzil / Islamic Network catalog).

Quran.com — Indo-Pak Naskh (text_indopak) for Hifzi-style reading by ayah.

English translation (default)

en.sahih on Al Quran Cloud — Sahih International translation.

Tafsir

Quran.com API (Ibn Kathir, Ma'arif, Bayan-ul-Quran, Ibn Kathir Urdu, Russian/Bengali tafsirs) and AlQuran Cloud (Muyassar, Jalalayn, Qurtubi).

Recitation audio

AlQuran Cloud resolves per-ayah MP3 URLs (Islamic Network CDN; bitrate varies by reciter).

Word-by-word

Quran.com API — Uthmani word text + English gloss per word.

Azkar

Short adhkār with collection/hadith references (e.g. Sahih Muslim, Hisn al-Muslim). Wording is stored in-app for offline use — verify against the cited book if you need exact isnād or wording.

Reader UI only — not a fatwa or tajwīd authority. For a certified print mushaf, use your local Islamic authority's edition.
